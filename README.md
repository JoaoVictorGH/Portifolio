## 🇧🇷 Português

### Sobre o projeto

Site estático de portfólio publicado no GitHub Pages. Um único `index.html` com React via CDN e internacionalização (PT/EN/ES) no objeto `I18N`.

### Como editar os textos (3 idiomas)

- Todos os textos ficam no objeto `I18N` dentro de `index.html` (blocos `pt`, `en`, `es`).
- Mantenha a mesma estrutura de chaves nos três idiomas.
- Após editar, abra o `index.html` num servidor local para validar.

### Publicação

- Hospedado via GitHub Pages a partir da branch `main`.
- Para publicar: push da branch, Pull Request e merge na `main`.

## 🇺🇸 English

### About the project

Static portfolio site hosted on GitHub Pages. Single `index.html` using React via CDN with PT/EN/ES i18n in the `I18N` object.

### How to edit texts (3 languages)

- All texts live in the `I18N` object inside `index.html` (blocks `pt`, `en`, `es`).

- After editing, open `index.html` on a local server to validate.

### Publishing

- Hosted via GitHub Pages from the `main` branch.
